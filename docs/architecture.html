Factory Inventory Management — Architecture

A full-stack demo application: a Vue 3 single-page frontend, a Python FastAPI backend, and in-memory mock data loaded from JSON files. No database — data is read into memory at startup and filtered on the fly.

Data Flow

  1. User adjusts a filter

    A selection in FilterBar.vue updates shared refs in the useFilters composable (global singleton state).

  2. View reacts and requests data

    The active view (e.g. Orders.vue) watches the filters, calls getCurrentFilters(), and invokes a method in api.js.

  3. API client builds the request

    api.js serializes non-'all' filters into query params and issues axios.get('http://localhost:8001/api/orders?warehouse=London&status=delivered').

  4. FastAPI filters in memory

    The route reads query params, then apply_filters() and filter_by_month() narrow the in-memory list. Pydantic validates the response shape.

  5. Response renders

    JSON returns to the view, is stored in a ref, and computed properties re-render the table or charts reactively.
